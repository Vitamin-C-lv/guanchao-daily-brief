# 日报／周报结构化取数层

这层把“取数”和“写作”拆开。`gpt-5.6-luna` 不再负责从搜索摘要猜测成交额、成交量、行业广度或集中度；它先运行确定性工具，再使用小型 `writerPacket` 写日报。周报读取本周压缩快照，不重新抓取或保存新闻全文。

## 运行入口

```powershell
pnpm market:data:daily -- --phase morning
pnpm market:data:daily -- --phase close
pnpm market:data:weekly
pnpm market:data:health
pnpm validate:market-data
```

`market:data:daily` 默认先执行 `rotation:refresh`，使 12 项行业历史、冻结模型推理和证据包使用同一完整交易日。只做本机诊断时可在脚本层传 `--skip-rotation-refresh`，正式自动化不得跳过。

## A 股链路

1. 中证官网日频接口：12 项观察指数最近 25 个完整交易日的收盘、成交额和真实成交量。
2. 中证全指 `000985`：同一发布方的全市场基准与成交份额分母。页面必须保留“中证全指样本口径”，不得扩写成沪深京全部上市证券。
3. 中证官网样本列表：只在内存解析 `.xls`，保存代码、日期和哈希后的 gzip 快照，原始工作簿随即丢弃。
4. 腾讯批量收盘行情：只在返回日期等于目标完整交易日、且成分股覆盖率达到 90% 时计算上涨广度和前三大成交集中度。

工具严格计算：

- 成交额比 = 最近 5 个完整交易日日均成交额 / 此前 20 日日均成交额；
- 真实成交量比 = 最近 5 日日均真实成交量 / 此前 20 日日均真实成交量；
- 成交份额比 = 最近 5 日“行业成交额 / 中证全指成交额”的日均值 / 此前 20 日同口径均值；
- 相对收益 = 行业 5 日收益率 - 中证全指同期收益率；
- 上涨广度 = 目标收盘日上涨成分股 / 可比成分股；
- 前三集中度 = 目标收盘日成交额最高三只成分股 / 全部可比成分股成交额。

只有六个字段全部通过日期、来源与覆盖校验时，行业才有资格写 `verified` 或 `none`。三项量比同时达到 1.35、1.20、1.15 才能写“明显放量”。缺一个字段时，只把该字段和该行业的严格发布状态标成 `insufficient`，不抹掉其他已核验数值。

## 港股边界

恒生指数公司公开接口可稳定提供当前 12 个恒生综合行业指数快照；连续行业历史量价属于不同的公开／授权边界。工具会保存当前快照、日期和覆盖率，但不会让写作模型从新闻页面补造一周或一月历史。随着本地日度快照积累，可以先增加价格连续性；要发布与 A 股同强度的量能结论，仍需同口径成分、主板成交分母和可回测的历史成交序列。

## 文件与体积

- `data/market-evidence/latest.json`：日报写作入口；
- `data/market-evidence/weekly.json`：最近 5 个不同交易日的周报输入；
- `data/market-evidence/snapshots/*.json.gz`：每日早／晚压缩快照；
- `data/market-evidence/constituents/*.json.gz`：去重后的官方成分快照；
- `data/market-evidence/health.json`：离线覆盖与时效检查。

整个目录上限 64 MB，最多 560 个日报快照，每个指数最多保留 6 个不同成分版本。不保存网页全文、PDF、原始工作簿、图片或请求响应。

## 故障语义

- `ready`：这个层级的强制字段齐全；
- `partial`：部分字段可用，写作时逐字段使用；
- `insufficient`：必需日期、口径或覆盖未通过；
- `licensed-boundary`：不是模型能力不足，而是公开数据范围不含所需历史。

所有失败均保留来源、目标日期、覆盖率和原因。自动化不得把请求失败转换成零值，也不得因一个供应商失败并发轰炸东财或其他站点。
