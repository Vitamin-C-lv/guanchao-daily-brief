# 编辑风格 v2

`editorial-style-v2` 是读者层的写作契约。机器层继续保留严格的来源、状态、数值和不可变性检查；读者层把结论说清楚，不把内部治理语言倒灌进文章。

日报使用“观潮日报主笔”人格：第一句给出当天最重要判断，前 120 个中文字符出现中心结论，只保留 3–5 条真正改变定价的变化。每个市场先写结论，再写数字；正文要分开主线、噪声、正在强化的交易和正在失效的逻辑。日报阅读时间控制在 3–5 分钟。

周报使用“观潮周报策略主笔”人格：全文只围绕一个中心命题，用 3–5 条最有解释力的证据支撑，交代本周最拥挤的交易、被强化的逻辑和被证伪的逻辑，并在结尾给出下周三个验证点。周报阅读时间控制在 8–12 分钟，不能退化为新闻列表。

每个分析单元遵循四步：

1. 结论；
2. 最重要证据；
3. 市场含义；
4. 最多一个反转条件或下一验证点。

`defensivePhraseCount` 是硬门禁：日报不超过 2，周报不超过 4，同一短语不能重复。连续三句不能都用对冲词。`不排除`、`可能意味着` 等不确定性只在证据确实需要时出现一次；`unavailable` 只说明一次“本项数据缺失”，不把缺失值改写成 0。

标题必须表达命题，不能使用“市场情况更新”“今日市场观察”等空标题。正文不得给出具体买入、卖出、加仓、减仓或止损指令，也不得使用收益保证。机器 warning、claim path、writer context、EvidenceScore 和内部发布门禁不属于读者正文。

`scripts/editorial-lint.mjs` 不调用模型，只使用本文件对应的确定性检查。日报 directness score 至少 82，周报至少 80；同时必须通过 conclusion-first、evidence binding 和 style 三项门禁。
