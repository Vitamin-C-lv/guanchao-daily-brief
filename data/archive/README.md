# 本地早报归档

此目录用于保存每日 AI 早报的本机压缩快照。每份归档只包含：

- 结构化摘要与市场数值；
- 文章标题、时间、标签和影响提示；
- 原始来源名称与可点击 URL；
- 归档时间、内容哈希和来源数量。

不会下载或保存新闻全文、PDF、视频、网页图片或行情历史库，因此单份文件通常只有几 KB。

`pnpm archive:brief` 会自动：

1. 对 `content/daily-brief.json` 建立 gzip 快照；
2. 用 SHA-256 去重；
3. 写入本地 `index.json`；
4. 将归档限制为最多 400 份，总容量不超过 50 MB；
5. 超出上限时从最旧的快照开始清理。

压缩归档和索引只保存在本机项目文件夹，已从 Git 提交中排除。
